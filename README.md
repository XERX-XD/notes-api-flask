# Notes API (Flask)

A REST API for managing notes, built while learning backend fundamentals.

## Stack
- Flask
- SQLAlchemy (SQLite)

## Endpoints
- POST /notes — create a note
- GET /notes — list all notes
- GET /notes/<id> — get one note
- PUT /notes/<id> — update a note
- DELETE /notes/<id> — delete a note
